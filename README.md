# The Forgotten USB

Sebuah USB ditemukan setelah lama terlupakan. Pemiliknya merasa sudah menghapus sesuatu yang penting, tetapi mungkin masih ada jejak yang tertinggal. Tugas kalian adalah memeriksa isi USB tersebut dan menemukan flag yang tersembunyi.

Berkas soal tersedia dalam `dist` dengan nama `the_forgotten_usb.dd.zst`, yaitu disk image USB yang dikompresi menggunakan Zstandard. Ekstrak berkas tersebut sebelum melakukan analisis, dan pertahankan berkas asli selama pengerjaan. Format flag: `FLAG{...}`.
